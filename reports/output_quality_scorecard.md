# 1.0.0 历史验证边界

2026-09-28：新独立 Skill。用户明确取消盲评，要求三个独立 Agent 执行贴近真实生产的案例；不设置 without-skill baseline，不计算胜率，不覆盖 seedance-prompt。

## 本轮实际执行

三名无历史上下文的 Agent 仅读取新 Skill 与按需参考；各完成 initial / revision 两回合，共 10 条完整双语 Prompt（20 个语言块）。主 Agent 对照需求审阅实际输出，未只采信作者自评。

| 案例 | 路由与表演 | 结果 |
|---|---|---|
| 原创好莱坞式硬科幻《静默潮汐》 | 系统/纯文本 → 系统/优化；A 建立、C 操作不加表演，仅 B 识别与隐瞒启用 | 三条 8 秒与 B 替换稿；身份、空间、道具与修改范围保持。修正中英三分之四侧面术语 |
| 晨岸咖啡 18 秒 TVC | 系统/纯文本 → 系统/优化；初稿不读 acting，人物 B 修订才读 | 杯把右侧、暖白产品、声音、右半文案留白与末两秒停留保留；B 接杯表演局部生效 |
| Transit One FPV 12→8 秒 | 创建/纯文本 → 优化/纯文本；不读 acting | 真实门洞、连续空间、鞋静止、末 2.5 秒产品落幅；缩短真实距离。修正正文中的画幅设置及台角路径歧义 |

这是原创模拟生产需求，并非真实客户项目。三名 Agent 均全文读取 tasks/craft，未严格做到按段最小读取；实际应用保持了任务范围与表演按需边界。该上下文效率偏差如实保留，不算全项完美通过。

## 继承的研发证据

下列测试在同一方法的旧候选名称下执行，并非以新名称再跑一遍：15 条双语 recorded fixtures、4 个负向变异检出、22 项表演条件作者走查；它们不代表 LLM 路由准确率。

研发期间已用 sd2.5 生成 13 个样片，13 个任务终态成功，共 1116 积分；不等于 13 个创作合同通过。表演有停顿与浅笑但怀表位置不准；群像通道与涟漪部分失效；产品水环裁切及瓶颈伸长；首尾帧右移成立，纯文字 I2V 位移两次未达标；杯外壁改蓝但内壁仍白。未听审声音，0.5 秒抽帧不能排除全部闪烁，也未验证精准角度或像素一致。CLI 请求 seedance2.5，响应未给独立 resolved model ID。
