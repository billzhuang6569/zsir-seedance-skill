# ZSir Seedance Master

### 把想法写成视频提示词，把一次灵感发展成一整套创作方案。

**为 Seedance 2.5 / 即梦视频打造的中英文提示词创作 Skill。**

你可以从一句想法开始，也可以带着已有提示词、参考素材或一整个系列的创作需求来。ZSir Seedance Master 会帮你写清楚：画面要发生什么、素材各自参考什么、哪些内容可以改变、哪些必须保留，以及镜头、表演和声音如何配合。

> “帮我写一段纸张折成帆船的视频提示词。”
>
> “这段提示词太长，帮我压缩，但别改台词和镜头。”
>
> “做三条产品短片，保持同一套环绕运镜，产品和场景可以不同。”

这些需求，分别对应它的三种核心工作模式：**创建、优化、系统**。

**技能版本：1.1.0 · 技能名称：`zsir-seedance-master` · 开源许可：MIT**

第一次了解 Skill？可以把它理解成给 AI 助手安装的一套创作方法。安装后，你通过聊天提出需求，助手按照这套方法给出提示词。**提示词（Prompt）就是交给视频生成平台的画面与声音说明**；拿到结果后，再去即梦等平台生成视频。

## 三种核心模式：从“写一条”到“做一套”

先看你现在想完成什么，再决定用哪种方式。

| 工作模式 | 用日常语言理解 | 你带来什么 | 它交付什么 |
| --- | --- | --- | --- |
| **创建** | 把想法或素材写成新的提示词 | 一个创意、一段脚本，或图片、视频、音频参考 | 完整中文与英文 Prompt |
| **优化** | 修改已有提示词，同时保护你已经确定的内容 | 原 Prompt、修改要求，或生成后的问题反馈 | 按要求修改、纠错、压缩或翻译后的完整双语 Prompt |
| **系统** | 给一组视频建立共同的创作规则 | 希望保持一致的角色、产品、风格、运镜或声音 | 简短的固定项与变量说明，加上每条独立完整的双语 Prompt |

### ① 创建模式：把“我想要……”变成具体画面

适合你有一个想法，但还没有完整提示词的时候。

它会先抓住观众应该看到或听到的结果，再根据任务补齐必要的动作、材质变化、镜头、光线和声音。故事短片、产品变化、抽象动画、教程演示，都可以从这里开始。

**可以这样说：**

> 使用 ZSir Seedance Master，写一个纸艺动画视频提示词：一张蓝色纸折成帆船，再沿桌面滑行停下。保留纸张厚度和折痕，固定镜头，不要人物。

或者：

> 我提供一张产品图片，把它作为开场画面。只让杯壁上的水珠缓慢滑落，杯子和镜头保持不动，写中英文 Prompt。

它会按需求选择纯文字、单帧驱动或其他素材任务。产品演示可以直接围绕产品变化展开；需要叙事时，再组织故事和人物反应。

### ② 优化模式：改你想改的，保留已经定好的

适合你已经有提示词，希望继续打磨的时候。

你可以让它缩短文字、翻译成英文、解决互相矛盾的要求，或针对生成结果提出修改。它会先明确修改范围，保留原来确定的主体、事件、台词、参考素材、风格、时序和结尾状态，再处理需要改变的部分。

**可以这样说：**

> 把下面的 Prompt 翻译成英文，人物仍然用普通话说“别等我了”。保留原台词、机位和动作，不增加剧情。

或者：

> 这段提示词同时写了“一镜到底”和“切到产品特写”。帮我消除冲突，保留一镜到底和最后的产品展示，输出完整的新版本。

**拿到的是完整替换稿**，可以直接复制，不需要把几段修改意见自行拼起来。

提供生成结果时，它可以结合反馈提出修复方向；只有文字、没有成片时，则检查提示词中的风险和矛盾。

### ③ 系统模式：让每条视频都属于同一个系列

适合产品系列、角色系列、视觉主题或固定运镜的连续创作。

你先告诉它哪些内容必须保持一致，哪些允许变化。它会把共同规则展开到每一条提示词里，让每条都能独立使用。

**可以这样说：**

> 建立三条产品视频提示词：固定从正面绕到产品右前方的相机运动，产品始终不自转，结尾停留。主体分别是陶瓷杯、纸风车和香水瓶，场景可以变化。每条都给完整中英文 Prompt。

它会先整理：

| 固定项 | 可变项 |
| --- | --- |
| 相机起点、移动方向、结束位置 | 产品主体与环境 |
| 主体不自转 | 材质、颜色与产品本身的动作 |
| 结尾有观看时间 | 各条的具体展示内容 |

随后，为每个主体写出对应的完整镜头过程。杯子可以通过杯把位置变化体现环绕，纸风车可以通过侧面厚度体现视角变化。

**每一条都会写全共同规则，不用“同上”或未替换的占位符。** 系列可以共享风格或运动，也可以共享角色和产品；不要求每条都讲同一个故事。

## 素材怎么用？按“它控制什么”来安排

创建、优化、系统决定你在做什么；下面这些任务决定图片、视频、音频具体怎么参与。

比如“优化一段首尾帧提示词”，就是**优化模式 + 首尾帧任务**。一段视频里包含多个镜头，仍然可以只是一次创建任务；当多条提示词需要共享规则时，才建立系统。

| 素材任务 | 它的含义 | 典型需求 |
| --- | --- | --- |
| **纯文字** | 从文字中的主体和事件构建画面 | “一张纸折成帆船，沿桌面滑行。” |
| **单帧驱动** | 用一张图锁定开场，补充运动和变化 | “以这张图开场，只让水珠滑落。” |
| **多模态参考** | 让不同素材分别控制外貌、动作、运镜、风格或声音 | “人物用图一，动作参考视频，背景重新设计。” |
| **首尾帧 / 关键帧** | 按指定画面顺序，设计状态之间的连接过程 | “从闭合雨伞变成完全撑开的同一把伞。” |
| **源视频编辑** | 以一段视频为母版，指定只改哪里、保留哪里 | “只把第 3–5 秒的墙面灯光改成暖色。” |
| **后续延长** | 接着已确认的结尾，继续设计后面的内容 | “纸船已经停下，下一段让船帆慢慢放平。” |
| **前置延长** | 补充之前的内容，让新增片段结尾接上原片开头 | “原片从坐下开始，补一段走来拉椅子坐下。” |
| **桥接转场** | 设计两段已知素材之间怎样离开和到达 | “红伞遮满画面，再移开露出咖啡馆。” |

### 人物、动作、镜头，可以分别参考

一份参考视频可以只提供动作，也可以只提供运镜。它会把借用范围写清楚，例如：

> 只参考视频中的动作节奏，人物外貌由图片定义，不继承原演员、服装、背景或声音。

同一个人物的多张照片会被明确映射到同一个角色；多个角色则有稳定名称和台词归属。这样，你可以表达“借这个动作，但不要这个人”或“借这个镜头，但换掉环境”。

### 首尾帧与关键帧：每张图都有自己的位置

它会分别写清哪张图是开始、哪张图是结束、中间图对应哪个状态，再设计连接过程。

人物姿势、持物、方向、尺度和镜头位置都要能接上。如果两个状态很难在指定时长内连接，它会提出过渡、调整时长或拆分片段的建议。

素材引用沿用你或平台实际提供的标记。多模态参考中的首尾图可以显式写入 Prompt；具体入口和素材绑定方式按你使用的平台确认。

### 视频修改、延长和转场：先锁清楚边界

- **局部编辑：** 指定唯一原视频、修改对象、时间范围和保留项。只换声音时，也会明确哪些视觉内容和其他声部需要保留。
- **向后续写：** 从原片实际结尾的姿态、位置、方向和声音继续，不重演已经发生的事件。
- **向前补片：** 新片段的结束状态要到达原片开头，不提前演出后面的内容。
- **桥接转场：** 写出触发物、覆盖或变化过程，以及到达新场景的状态。例如伞面怎样遮住画面、怎样移开。

延长和转场需要源片或明确的边界描述。你提供的描述与助手实际看过的素材会被区分，缺少关键边界时会先问清楚。

## 更进阶的素材，也有对应方法

### 分镜板与图片成片

分镜板是一组按顺序排列的镜头草图。它会根据阅读顺序说明每格的动作、构图和最终画面风格，并排除格线、注释等辅助内容。

想把多张图片组织成视频时，它会写清出场顺序、每段运动量、停留节奏、过渡和声音。图集展示也可以直接围绕图片呈现来设计。

### 白模预演：先定运动，再定外观

白模可以理解成用简单或无材质的三维模型预演画面。

| 白模类型 | 用来决定什么 | 它如何写提示词 |
| --- | --- | --- |
| **粗白模** | 大致空间、运动路径、相机和切镜 | 说明几何体对应哪个最终主体，保留运动与调度，再指定成片外观 |
| **精白模** | 已经完整的结构、动作与相机 | 保留这些结构，重点重写材质、颜色和渲染风格 |

例如，白模里的球体可以代表最终的飞船，方块代表山体。提示词会明确继承飞行路径和相机，最终采用指定材质，并排除坐标轴、路径线、界面等预演辅助元素。

### 音频驱动：让节拍对应具体变化

可以用音乐或声音来设计动作时机，例如：

> 一个橙色柔性球体在每个主鼓点到达时收缩，在两个鼓点之间恢复大小。固定镜头，不加人物或剧情。

它会说明哪个声部或节拍对应哪件事。音频能否单独作为输入、有哪些参考限制，以实际平台入口为准。

## 它的特别之处

### 先保护创意，再补齐实现它所需的信息

用户已经明确的台词、时序、视觉方向和修改范围会被保留。它根据当前任务补充必要的信息：简单画面可以只有几句话，复杂片段才展开时间段和镜头段。

创作可以是叙事，也可以是产品变化、自然观察、图形运动或抽象循环。具体采用哪种组织方式，由你想让观众看到的结果决定。

### 把“参考一下”写成明确的分工

外貌、衣服、动作、镜头和声音可以来自不同素材。它会明确哪份素材决定哪项属性，以及哪些内容不需要继承。

如果两份参考要求同一项属性呈现不同结果，会先处理冲突，避免把互不兼容的要求一起写进提示词。

### 相机写清路径和终点

“镜头动起来”会被进一步写成：从哪里出发、相对于主体怎样移动、到哪里结束、最后看见什么。

需要时，它会区分容易混淆的拍法：

| 镜头需求 | 具体区别 |
| --- | --- |
| 相机走近 / 画面变焦放大 | 相机位置变化 / 焦距变化 |
| 原地转向 / 横向移动 | 相机朝向变化 / 相机位置侧移 |
| 变焦 / 移焦 | 取景范围变化 / 清晰对象从前景转到背景 |
| 相机环绕 / 主体自转 | 相机绕着主体走 / 主体自己转动 |

跟拍、环绕、主观视角、穿行和复合运镜会根据起点、路径、阶段交接与结束画面来描述。固定镜头也可以成为合适的选择。

### 表演按需要设计，帮助反应在画面里成立

当角色的反应、决定、倾听或潜台词是重点时，它会用视线、停顿、面部变化或身体动作把要求写具体。

比如“她掩饰失望”，可以写成接收到信息后的短暂停顿、勉强提起的嘴角，以及说完话后逐渐放松的表情。

只有人物出现在画面里时，并不一定需要这些细节。单纯展示妆容、行走、舞蹈或产品的镜头，会根据实际需求处理；你只要求修改表演时，也会保留原场景、机位和台词。

### 连续动作可以分阶段，结尾状态也要明确

动作链可以包含准备、接触、反馈和停稳。它会检查动作和相机之间的关系，区分连续过程与真正的切镜。

多镜头还会关注人物、道具、空间、方向和声音的衔接。相机在动时不锁死不该固定的画面关系；物体需要变形时，则说明哪些阶段允许变化、成形后保留什么。

### 双语一致，台词保留你要求的原语言

中文与英文版本来自同一份确定内容，素材标记、时间、数量、位置和保留范围对应一致。

**英文 Prompt 里的中文对白仍然可以保持中文。** 例如角色必须说“别等我了”，英文版会保留这句原文并注明普通话，不会自动改成英语对白。

歌词和画面里的准确文字也按照你的语言与原文要求处理。

### 系列里每一条，都可以单独拿去用

共同规则会被逐条展开，主体或场景的变化也会落到具体画面里。你可以只固定运镜，也可以固定角色、产品、材质、色彩关系或声音动机。

修改系列中的某一条时，可以明确只调整这一条，保留其他条目；需要更新整套规则时，再说明新的固定项和允许的例外。

## 拿到的结果长什么样？

默认输出简洁，包含：

1. **当前模式：** 例如“创建 / 源视频编辑”。
2. **中文 Prompt：** 一段完整、可复制的正文。
3. **English Prompt：** 语义一致、可独立复制的英文正文。

必要时，素材绑定说明或关键假设会放在正文之外。系统模式会先列出简短的固定项与变量，再逐条给出完整双语 Prompt。

下面的示例来自包内 [输出用例](examples/prompts.md#edit-01)，展示提示词格式，不是对应生成效果的保证。

### 你的需求

> 我提供的视频是唯一原视频。只在第 3–5 秒把右侧墙面的冷蓝灯光改成暖橙色，人物、动作、镜头和对白都保留。

### 当前模式：创建 / 源视频编辑

中文 Prompt

```text
编辑 @视频1。它是唯一编辑母版。仅在3–5秒把右侧墙面的冷蓝灯光改为暖橙色，允许墙面反光自然影响邻近皮肤受光。保留原人物身份、服装、动作、相机路径、构图、事件顺序和完整原对白及环境声；其它时间段与区域不变。
```

English Prompt

```text
Edit @视频1 as the sole editing master. Only during 3–5 seconds, change the cool blue light on the right wall to warm orange, allowing its reflected light to affect nearby skin naturally. Preserve the original identities, wardrobe, actions, camera path, framing, event order, complete dialogue, and ambience. Keep other time ranges and regions unchanged.
```

这里的 `@视频1` 是用例中的素材标记，使用时应绑定你的实际原视频，并沿用平台插入的标记。

更多例子包括纸艺动画、人物对白、单帧驱动、首尾帧、前后延长、桥接转场、白模与音频驱动，见 [examples/prompts.md](examples/prompts.md)。

## 第一次使用：从一句需求开始

1. **在支持 Skill 的 AI 助手里安装。** 安装后开始新会话，让助手发现技能。
2. **说出要创建、修改或系列化的内容。** 有 Prompt 或素材就一起提供，说明最想保留的部分。
3. **复制提示词到视频平台。** 按平台入口绑定素材、设置参数并生成；需要继续调整时，带回原 Prompt 和结果反馈。

不知道怎么开口，可以复制：

> 请使用 zsir-seedance-master 技能，为 Seedance 写完整的中英文视频 Prompt。我的需求是：……

已有提示词时：

> 使用 zsir-seedance-master 优化下面的 Prompt。只调整……，保留……。输出完整中英文版本。

做系列时：

> 使用 zsir-seedance-master 建立三条系列 Prompt。固定……，允许变化……。每条独立完整，中英文版本。

## 常见问题

### 会帮我直接生成视频吗？

这个 Skill 负责创建、优化和组织视频提示词。视频生成、素材上传、剪辑和下载在你使用的相应平台或工具中完成。

### 不懂编程和摄影术语，可以用吗？

可以。用自己的话说明想看到的结果即可。比如“只换墙面颜色”“人物听完再回答”“保持产品不动，相机绕到右侧”，都能成为明确的创作要求。

### 必须选好所有模式和任务吗？

你可以直接指定，也可以说明自己有什么、要做什么，让助手判断。最有帮助的信息通常是：目标结果、已有素材、哪些要改、哪些要保留。

### 只有参考视频，没有旧 Prompt，算优化吗？

可以用创建模式，为参考视频写新的局部修改指令。优化模式主要用于修订已有 Prompt；“修改原视频”和“修改提示词”分别描述素材任务与工作模式。

### 所有图片、视频、音频，助手都能读吗？

素材识读取决于你使用的 AI 助手。无法读取时，可以提供关键帧、动作或边界状态描述；尚未核验的部分会与已观察内容区分。提供给助手的素材和上传到生成平台的素材，也需要分别按工具要求处理。

### 能保证人物一致、精确运镜或无缝转场吗？

提示词会写清这些目标和约束，实际效果仍需要检查成片。对身份、产品结构或运动精度要求高时，共享视觉参考、关键帧、动作或白模参考通常更有帮助。

### 支持哪些时长、分辨率和素材数量？

这些由模型、平台入口和账号能力决定。仓库中的 [能力与来源说明](references/surface-and-sources.md) 记录了作者核验时的信息；使用时以当前平台为准。Prompt 中的时间段用于安排创作节奏。

### 是否需要 API Key？

技能文件本身不需要 API Key，也不包含视频执行脚本。AI 助手和视频平台所需的账号、订阅或额度，按对应服务要求准备。

### 可以用于商业创作或自行修改吗？

可以。本仓库采用 MIT 许可证，允许使用、修改和再分发，包括商业用途；请保留版权声明与许可证。
