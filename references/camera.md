# 相机控制：按机制编译，按画面验收

只在入口命中时读本文件；相机控制不新增工作模式，也不自动启用人物表演。保留用户锁定机位、参考轨迹与修改范围；翻译只消歧，不重新导演。

## 分清控制维度

把实际需要的控制分别落到位置、朝向、焦距、焦点、稳定质感、视线归属和剪辑连续性。它们可组合，不必全部写满。设备名只作风格提示，最终用可见路径和画面关系定义。

| 易混概念 | 必须区分的变化 | 编译检查 |
|---|---|---|
| 摇摄 pan / 横移 truck | 原地水平转向 / 机位侧移 | 从哪个对象到哪个对象；侧移的近远景关系不能写成原地转头 |
| 俯仰 tilt / 升降 pedestal | 原地上下转向 / 机位改变高度 | 高度与朝向分别决定，可同时改变但要说清 |
| 推拉 dolly / 变焦 zoom | 机位接近或远离 / 焦距改变 | 推拉允许透视关系变化；变焦不冒充穿过空间 |
| 变焦 zoom / 移焦 rack focus | 改取景范围 / 改清晰距离 | 移焦指定起止对象、前后距离与清晰度交接；相机可保持不动 |
| 翻滚 roll / 荷兰角 Dutch angle | 绕光轴持续转动 / 保持倾斜构图 | 明确方向、地平线如何变化及结束姿态，主体不随相机自转 |
| 手持 handheld / 稳定器 stabilized | 运动质感与惯性不同 | 两者仍需路线；轻微手持不等于随机乱抖，稳定不等于机位不动 |

焦距数字是创作目标，不保证模型精确执行；不要用固定焦距、固定距离和任意景别同时强锁不相容的画面。移焦需存在能分开的距离平面和可见虚实差异；深景深中只换对象名称未必产生可读变化。

## 相对运动与特殊控制

- 跟拍：写相机在主体前、后或侧面；想保持主体大小时控制相对距离与焦距。主体和相机都向前不等于距离固定。靠近、超越或环绕期间可更新距离约束，不能一边锁关系一边要求改变关系。
- 环绕：指定相对起始方位、沿哪侧路径到达哪个可见面。角度与最终方位冲突时先解决；不能把任意背面到正面写成固定四分之一圈。主体自身转身与相机绕行分开。
- POV：视线属于谁、看哪里、可见哪些手脚或持物。普通 POV 不同时外拍自己的完整正面；镜面等特殊关系需明确。角色视角可以静止，不自动加速或加脸部表演。
- FPV/航拍：写真实开口、空间节点、净空、高度和减速落点；飞行可以缓慢。转弯倾斜与滚转分别决定，禁止用穿透实体或瞬移填补不可达路径，除非用户明确要超现实机制。
- Dolly zoom：相机后退时增加焦距，或前进时减小焦距；以主体画面尺寸大致稳定、纵深背景的相对尺寸变化为目标。不能同时锁焦距；不要用普通放大或主体变形替代。复杂光学效果只在需求匹配时选用，必要时建议参考，不承诺一次成功。

## 复合运动交接

先区分同时联动与先后阶段。仅对需要的阶段写：当前相对位置与构图 → 触发事件或空间节点 → 下一运动 → 可见结束构图。下一阶段从上一阶段的位置、方向、速度状态接续；若需要明显停顿或重新加速，给出过渡预算。

触发点可以是听完一段信号、主体停步、越过门框等；不能把依赖事件的动作擅自提前到开场。时间标记可辅助，不假装精确到帧。

先验收路径可到达、主体可读、落幅有观看时间；超预算时缩短距离、减少次要变化或建议拆镜。不要硬规定每镜只能一到两个动作，也不把情绪机械映射成固定运镜。已有表演或产品变化足以表达意图时，固定镜头仍是有效选择。
