# 生成任务编译

只读当前任务段。参考 token 保持用户/平台原样；下面的 @图片1 等仅为示例，未绑定素材时不能冒称已上传。

## 纯文本

从主体与事件建立画面；补充真正影响结果的环境、媒介、相机、光与声。一个自然连续动作可包含准备、接触、反馈；不因“多个动词”自动切镜。需要不同空间/视角/时间时才分段，并明确衔接。

## 单帧驱动

图像锁开场构图、主体、外观与场景；只补图片没有的运动、过程、光变、音轨和落幅。只说明需要稳定的属性，不把整张图重写成可能冲突的新设定。相机运动后可以露出新区域，但不能承诺未看到区域与原图完全一致。

写运动前检查画面剩余空间：主体已靠右时，“固定相机、向右移动一整个身位、全程完整入画”可能无法同时成立。先指出冲突，再选择用户允许的更合适参考帧、较短位移或跟拍；不能默默反转方向、缩小主体或改变镜头。本次测试发现的这类问题属于素材/空间预检，不应靠更多稳定性形容词补救。

## 多模态参考

按上传 token 分配控制属性与排除项；同一主体的多视角明确为同一个实例。多角色用稳定名称和台词归属，每个镜头只选需要的素材。

视频参考先问它控制什么：人物身份、动作、运镜、节奏、声音、完整母版不是同一件事。只迁移动作时明确不继承演员、服装、背景或原音轨。相机路径与主体运动分开写。

音频驱动：定义声部、时间段、节拍对应事件，画面主体由文字或图像定义；是否支持纯音频输入依实际入口确认。不要为了满足某个 CLI 的输入要求虚构图片。

### 分镜与图片成片

分镜板提供故事顺序和大致构图：写清阅读顺序、每格动作与镜头、最终渲染媒介，排除格线/注释/占位人物。除非用户要漫画拼版，不把整个网格当一张画面拍。

图片成片：定义图片的出场顺序、每段运动量、停留节奏、过渡与声音。若用户只要图集演示，不擅自添加剧情。

### 粗白模与精白模

粗白模是动作与空间预演：逐一映射简单几何体到最终主体；指定继承路径、调度、相机和切点，外观交给其他来源。

精白模是已有完整结构：保持模型拓扑、动作和相机，主要重渲染材质、颜色和风格。坐标轴、路径线、相机视锥不是成片元素。两者不确定时根据素材实际结构判断，不仅看“白模”这个词。

## 首尾帧与多个关键帧

每张锚点单独定义角色：哪张是第一帧、哪张是最后一帧、中间图对应哪个状态。描述连接过程而不是重新设计锚点；额外身份/材质参考不能覆盖首尾构图。

检查姿势、持物、方位、尺度、镜头位置能否在时间内连接；不合理时建议过渡、时长或拆片，不声称模型能自动解决。首尾比例不同会产生适配风险；参数限制见能力文件。全能参考可显式引用首尾图，不能沿用旧版“首尾帧绝不写 @”的通则。

## 源视频编辑

第一句指定唯一母版。明确对象/区域、时间范围、操作（增加/移除/替换/调整）以及目标参考的属性。保留未改区域、事件顺序、相机和声音；根据修改性质允许合理连带变化，例如新灯色对应皮肤受光。

只有声音变化时也走编辑任务：锁视觉，指定换配音/音色/语言/背景音乐中的哪一项，保留其它声部。多母版冲突先澄清；不得把多个视频混称唯一母版。

## 后续延长与前置延长

需要已接受源片段及边界实际状态。后续延长（forward extension）从源片末态继续；前置延长（backward extension）新增内容的末态到达源片首态。观察人物姿态、道具归属、视线、运动方向/速度、相机阶段、光照、声音延续。

已发生事件不重演；后续才出现的人物/道具不得提前入场。未看到源片或边界时，索要源片/边界描述；可以给标注待补的草稿，但不能虚构“观察到的结尾”。逐帧无缝是验收目标，不是提示词保证。

## 桥接转场

两段分别承担“离开”与“到达”边界：触发物 → 覆盖/运动/形态变化过程 → 揭开后的到达状态；同时定义空间、动势、曝光/颜色与声音衔接。遮挡转场要交代何物覆盖镜头、怎样离开，不能只写“无缝”。一镜到底与显式剪辑相冲突时先解决。

## 时间线规则（跨任务）

单镜、分阶段长镜头、多镜头三者分开。分阶段不等于切镜；指定“不切镜”后，每段相机位置必须能连续到达。多镜头允许合理镜头组，不强制每镜只做一个动作。

时间段连续不重叠，留出台词、接触反馈与结尾观看时间。节拍点允许写，但不宣称精确到帧。超单次能力的内容拆为独立片段，每段有完整 Prompt；连续片段的未生成结尾只能叫计划状态。
