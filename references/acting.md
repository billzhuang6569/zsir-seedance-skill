# 人物表演：条件加载

仅在入口判定命中后读取。这里的“微表情”指创作中的细微表演，不是识谎工具或医学分类；不把肌肉编号、毫秒数或表情词当作模型精确控制接口。

## 先确定作用范围

按入口的六类触发判定：面部信息中心、明确/已有细节、情绪/决定、互动/潜台词、表演修复、表演参考/系列共性。场景和群像默认关闭；群像中明确指定某人的反应，仅写该人的局部表演，不让所有人同步反应。远景若通过后退、停步等动作表达明确情绪，也可仅用身体表演，不强塞看不清的脸部细节。一个系列只对命中的成员/镜头加载，不升级为全系列默认项。

拟人动画、面具人物、动物或无面孔角色只有明确表演目标时才启用；按可动部位选择姿态、节奏或朝向，不给无眉毛的机器人编眉间肌肉。舞蹈、打斗和走位默认交给动作控制；只有要求犹豫、恐惧、轻蔑等角色表达时才叠加相关表演。

保留已有事件、角色关系、视线目标、镜头与台词。只补表演时不得重写布景、光线或结局；翻译/压缩只保护已有细节。脸部特写若没有情绪要求，用与现有动作相容的自然状态即可，不编秘密、创伤或新的情绪转折。

## 把反应写成可拍摄的过程

先找已有的触发事件与角色正在做的事，再选少量能够被镜头读到的反应。需要情绪变化时，可组织为“触发 → 接收/短暂停顿 → 可见变化 → 继续动作或保留余韵”；不是每次都必须写齐四段，更不是固定时间轴。

- **视线**：看向谁/什么，何时停住、避开或重新对视；需要先看后转头时才写顺序，不当作所有情绪的定律。
- **面部**：选一个主要变化，如嘴角渐松、下颌放松、眉间短暂收紧；避免眉眼口鼻同时做满。幅度服从用户选择，克制、喜剧、动画夸张都可成立。
- **呼吸与身体**：用一个与事件相连的停顿、呼气、手部动作或重心变化辅助。不要给每个镜头强加屏息、吞咽、颤抖或连续眨眼。
- **倾听与对白**：先接收到信息再回应；沉默时也可保持对视或继续手头动作。口部动作不能与发声冲突，不同时要求说话和全程抿紧嘴唇。保留原台词与语言，别自动加抽泣、喘息或旁白。

需要潜台词时，区分“角色要做什么”和“外在如何控制自己”，最终落到动作；没有这类需求时不制造内外冲突。只选能推动这个镜头的两三个信号作为起点，可按用户要求增减，这属于本 Skill 的简化写作策略，不是官方数量限制。

## 与镜头、参考和连续性合并

细微变化需要可见的脸、合适景别和足够停留时间。不能一边远景/遮脸/快速甩镜，一边承诺读清嘴角微动；镜头已锁定时改用可读的身体反应，或在正文外指出限制，不自行改成特写。

身份参考控制骨相、年龄特征、发型等；表情、眼睑和口部允许随表演变化，不能用“脸全程不变”冻结表演。表演参考只借指定节奏/动作，不顺带复制演员身份、声音或背景。跨镜延续上一镜的视线、手势与情绪落点；系列可固定表演习惯，但不能让每条重复同一表情。

## 优化与验收

| 问题 | 优先检查与最小修复 |
|---|---|
| 过度表演 | 删重复的强情绪词与并发动作，保留触发和主反应；不把整个脸锁死 |
| 僵硬、假笑 | 看是否只给静态终态；补与事件相连的进入/退出过程，不机械添加眨眼 |
| 突然换表情 | 检查触发是否明确、时间是否够；减少转折或保留短暂停顿 |
| 嘴动错位 | 分开倾听与说话，去掉与台词冲突的嘴部要求 |
| 表情变换伴随换脸 | 分离身份不变量与允许变化的表演部位，检查参考权威 |
| 细节不可见 | 先检查景别、遮挡与相机运动，不能靠堆更多肌肉词补救 |

审阅 Prompt 时检查事件与反应的先后、强度、动作兼容性和双语一致；审阅成片时再看反应是否可读、是否有无因抖动/机械重复、身份是否稳定、对白是否同步。文本通过不等于演员表演质量已实测提升。默认输出仍只有当前模式与中英文完整 Prompt，不额外输出表演分析表。

道具参与表演时先核对手、道具与身体的空间关系：例如“把表靠近耳边”需验收实际位置，不能只因末尾浅笑成立就判整段通过。本次样片出现怀表靠嘴，说明细微表情成立也不能替代动作验收；要求精确时优先使用清晰姿势或动作参考。

方法比较来源见 [能力与来源](surface-and-sources.md) 的人物表演补充。这里不复制社区整套情绪词库，也不宣称 FACS/AU 编号是 Seedance 原生语法。
