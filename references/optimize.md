# 优化：保留决策，只改失败维度

先识别修订目标：意图重写、纠错、压缩、翻译、失败诊断。用户已指定修改范围时直接照做；不要把翻译任务升级为重新导演。

1. 冻结原 Prompt 已决定的主体、事件、台词、参考 token、风格、时长与落幅。
2. 判断问题是缺信息、互斥约束、素材权威不清、动作过载，还是模型/入口不支持。没有成片时只能指出 Prompt 风险，不能断言实际失败原因。
3. 选一个最有证据的主修复；如果用户要求整体重写，可同时修复多个明确矛盾，并给极短修改摘要。
4. 用完整新 Prompt 替换旧版，不只交付要用户自己拼接的补丁。中英共同更新。

| 症状 | 首先检查 | 最小修复 |
|---|---|---|
| 外观/人数漂移 | 多图是否同一人，来源是否抢权 | 映射到同一实例，固定数量与关键外观 |
| 产品变形 | 动作是否与全局形体锁互斥 | 限定允许变化的部件/阶段 |
| 镜头乱切 | 一镜到底是否又含切换/跳空间 | 去掉冲突切点，写可达路径或承认多镜头 |
| 过度表演 | 抽象情绪与动作是否重复强调 | 一个触发事件、一个可见反应、合理停顿 |
| 动作糊或穿插 | 是否缺接触与受力结果、时间不足 | 起势→接触→反馈，减并行事件 |
| 风格串味 | 素材是否同时控制风格与身份 | 给风格单独权威，排除无关迁移 |
| 续写跳变 | 使用计划末帧还是实际末帧 | 从实际边界重写开场 |
| 系列只有换颜色 | 变量是否改变真实内容 | 在固定维度外换事件/场景/用途 |

压缩顺序：重复描述 → 空泛质量词 → 参考已定义的静态细节 → 不服务目标的次要事件。保留角色映射、关键动作、原文台词、时序、落幅与保留项。不要用固定英文词数决定中文内容质量。

翻译保留素材 token、数值与台词语言；用户要本地化台词时才改台词。短对白不足以承载所有信息时不凭空加旁白。

失败反馈只形成待测试假设。验收成片后再更新系统规则；一次成功不形成成功率。
