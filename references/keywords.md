## A. 运镜动作

### 基础运镜

| 中文 | English | 情绪/叙事效果 |
|------|---------|-------------|
| 推镜 | Dolly In / Dolly Forward | 情绪亲近、揭示细节 |
| 拉镜 | Dolly Out / Pull Out | 孤独、渺小、情绪释放 |
| 横摇 | Pan Left / Pan Right | 揭示空间、追踪主体 |
| 竖摇 | Tilt Up / Tilt Down | 建立高度感、仰望/俯瞰 |
| 变焦推进 | Zoom In | 焦距拉近，压缩空间感 |
| 平移 | Truck Left / Truck Right | 跟随或平行观察 |
| 升降 | Crane Up / Crane Down | 宏观视角、神性感、史诗 |
| 环绕 | Orbit / Arc Shot | 强调主体、仪式感 |
| 跟随 | Tracking Shot / Follow Shot | 沉浸感、参与感 |
| 固定镜头 | Static Shot / Locked-off | 时间在静止中流动 |
| 手持跟拍 | Handheld Follow | 纪实感、不安、亲密 |
| 航拍 | Aerial Shot | 宏观、孤独、史诗 |
| 甩镜 | Whip Pan | 切换、混乱、能量爆发 |
| 后拉揭示 | Pull Back Reveal | 反转、震惊、格局扩大 |
